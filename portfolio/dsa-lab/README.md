# DSA Universe — Ujjwal Painuly

An interactive DSA workspace published as part of my GitHub Pages portfolio.

## Live demo
https://ujjwal-painuly.github.io/ujjwal-portfolio/dsa-lab/

## What is inside
- 443 roadmap questions across 22 categories, imported from the DSA checklist in my portfolio.
- Search and filter by track/category, with completion progress saved locally in the browser.
- Graph Lab with step-by-step BFS, DFS and Dijkstra visualizations on a weighted graph.
- CSS 3D project architecture explorer for CivicFix and the DSA learning workspace. Drag the models to rotate them.
- Code Library linking to 64 Java source files in advanced-java-dsa and 53 Java solution files in leetcode-solutions.
- Direct links to original GitHub repositories, LeetCode problems and CivicFix live demo.

## Implementation
Vanilla HTML, CSS and JavaScript; Canvas graph rendering; CSS 3D transforms; localStorage progress; GitHub Pages deployment.

> The 3D architecture view is an explanatory model based on the project repository and README, not a live infrastructure telemetry view. Progress is stored only in the current browser.
